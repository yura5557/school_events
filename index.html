О проекте

Это учебный сайт с расписанием мероприятий школы №18. На главной видны ближайшие события. В полном расписании можно выбрать дату и класс.

Учитель вносит изменения в своём браузере. Браузер сохраняет список в localStorage. Чтобы передать расписание, учитель создаёт ссылку и отправляет её ученикам после размещения сайта по адресу, доступному получателям. По ссылке открывается копия списка для просмотра.

Карточки с отметкой «Пример» нужны для демонстрации. Их можно заменить настоящими мероприятиями в разделе для учителя.
